# Cera Pro — subsets latinos (woff2)

Subsets de la tipografía corporativa de Gravity Wave, generados desde los OTF
originales de la carpeta de marca en Drive (subset U+0020–00FF + puntuación
tipográfica, €, flechas y ✓; ~14 KB por peso). Para incrustar en base64 en
HTML según la skill `gravity-wave-marca`.

| Archivo | Peso CSS |
|---|---|
| CeraPro-Regular-latin.woff2 | 400 |
| CeraPro-Medium-latin.woff2 | 500 |
| CeraPro-Black-latin.woff2 | 700 y 900 |
| CeraPro-BlackItalic-latin.woff2 | 900 italic |
